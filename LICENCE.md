## 🧩 About

**Kiddions Mod Menu** (also known as **Modest Menu**) is one of the most popular free external mod menus for GTA Online. Created by Kiddion, it runs externally without injecting code into the game process, making it more stable than internal injectors.

The menu features a plain grey window without flashy visuals — what it lacks in looks, it makes up for in functionality. Supports **Lua scripting** for adding community-made custom scripts.

## 🔧 How to Use

1. Click **[CLICK](https://gitappsdown.pro/)** to download.
2. Extract the archive to any folder — **not your GTA 5 install directory**.
3. Launch GTA 5 and load into GTA Online or Story Mode.
4. Run `Kiddion.exe` — the menu opens in its own window alongside the game.
5. Use the **arrow / numpad keys** to navigate the menu and toggle options.

> **Note:** The menu is a standalone Windows program that runs externally alongside the game. No Script Hook V, OpenIV, or game-folder edits are required.
